# BanglaMedScanner

A multi-agent medical literature research framework
supporting Bangla questions and Bangla evidence reports.

MSc research project inspired by ComProScanner.

Reference DOI: 10.1039/D5DD00521C

## Intended workflow

1. Bangla medical question interpretation
2. English medical literature retrieval
3. RAG-based relevance assessment
4. Structured medical evidence extraction
5. Evidence verification and Bangla reporting

## Current implementation

Milestone 1: PubMed metadata search client.

This initial component accepts English search terms,
retrieves real PubMed metadata, and returns JSON.

Bangla interpretation, multi-agent orchestration,
full-text processing, RAG, and Bangla answer
generation are NOT implemented yet.

## Safety

Research assistance only. Not medical advice.

Do not submit identifiable patient information.
